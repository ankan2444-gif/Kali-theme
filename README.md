# Kali-Termux Theme

A clean, high-contrast **Kali Linux** & **Cyber-Skull** terminal theme for Termux with custom prompt naming and instant banner switching.

## Installation
```bash
pkg update && pkg install git -y
git clone [https://github.com/ankan2444-gif/](https://github.com/ankan2444-gif/kali-theme.git)
cd kali-theme
bash install.sh
### Kaise Kaam Karega:
1. User `bash install.sh` chalayega -> **Kali Dragon** banner aur **`┌──(kali㉿localhost)-[~]`** set ho jayega.
2. User `kaliset Madara` likhega -> Agli hi line me prompt **`┌──(kali㉿Madara)-[~]`** ho jayega.
3. User `show skull` likhega -> Screen clear hokar **Cyber-Skull** aa jayega, aur `show kali` se wapas **Kali Dragon**.
